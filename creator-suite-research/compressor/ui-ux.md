# Compressor — UI / UX

## Window structure and organisation
- Batch window with job list, Settings/Locations/Destinations sidebars
- Inspector for encoder parameters, preview window
- Shared Computers settings pane

## Menus and toolbars

## Keyboard shortcuts
Shortcut tables were **not harvested** from Apple's guide in this session (UNK).

## UX principles to preserve in our version (design choices, not observations)
- Keep primary workflow reachable within three clicks.
- Full keyboard operability and screen-reader labels.
- Native-feeling behaviour on Windows, Linux and macOS (own design, not a copy of Apple visuals or trade dress).
