# Final Cut Pro — UI / UX

## Window structure and organisation
- Main window with browser (libraries/events), viewer, inspector, and a timeline
- Magnetic Timeline: primary storyline plus connected clips/secondary storylines (DOC from guide structure; behaviour details to confirm)
- Menus: File, Edit, Trim, Mark, Clip, Modify, View, Window, Help (INF from standard Mac pattern)
- Separate Event Viewer, Color board/inspector panels, Effects/Transitions/Titles/Generators browsers

## UX principles to preserve in our version (design choices, not observations)
- Keep primary workflow reachable within three clicks.
- Full keyboard operability and screen-reader labels.
- Native-feeling behaviour on Windows, Linux and macOS (own design, not a copy of Apple visuals or trade dress).
