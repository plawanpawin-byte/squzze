# Creator Suite

Free, open-source, offline tools for creators. Independent implementations; not affiliated with Apple.

First app: **Squeeze** (working name), a batch media transcoder built on FFmpeg.

- Platform order: Windows `.exe` first, then Linux/macOS. iOS (`.ipa`) is later and needs a Mac to build.
- License: GPL-3.0-or-later (see `LICENSE`).
- Status: scaffolding. Nothing is released.
